# CIDM-3315-Final-Project

This webapp has two (main) pages: 
- Index (home), which shows all rarities, and the associated items. 
- Items/Index, which shows all magic items and associated properties, including a picture.

Both pages display data, and include "edit" and "delete" features. The Items pages (Items/Index) were created via scaffolding, and then modified.

There are 39 items in total, 7 types, and 6 rarities. 
There are 3 entity classes, both 1:M relationships.

Bootstrap was used to provide the theme of the webapp, and for the cards on the Items/Index page.

Items/Index also features pagination, sort (asc/desc), and search capabilities on the Item.Name property. 


This has been a challenging and rewarding project. I ran into substantial issues with seeding data, passing data to razor pages, and website formatting.
Although this webapp is not quite as pretty as it was when I initially came up with the idea, I am still proud of the result.

Thank you for a great semester!
